# AI/ML Crop Advisory System

> **Synthetic dataset generated for educational AI/ML demonstration.**
> All data in this project is artificially generated. It does not represent real farms, real measurements, or any real agricultural records.

---

## Overview

This project demonstrates a complete AI/ML pipeline for crop recommendation and yield estimation using **entirely synthetic agricultural data**.

Two machine learning models are trained:

| Model | Type | Task |
|---|---|---|
| Crop Recommender | Random Forest Classifier | Suggest top-3 crops from soil + climate inputs |
| Yield Estimator | Gradient Boosting Regressor | Estimate yield (tonnes/hectare) for given conditions |

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Generate the synthetic dataset

```bash
python generate_dataset.py
```

Creates `data/synthetic_crop_data.csv` with **3 000 synthetic records** (reproducible, seed = 42).

### 3. Train the models

```bash
python train_model.py
```

Outputs trained model artefacts in `models/` and a training report in `reports/training_report.txt`.

### 4. Make predictions

**Interactive mode** — enter parameters one by one:

```bash
python predict.py
```

**Batch mode** — run over the full dataset and write results to a CSV:

```bash
python predict.py --batch data/synthetic_crop_data.csv --out results/predictions.csv
```

## Dataset and Privacy

### ⚠ Synthetic Data — Not Real Agricultural Records

**This project does NOT use any real-world dataset.**

The dataset (`data/synthetic_crop_data.csv`) is **100% artificially generated** by [`generate_dataset.py`](generate_dataset.py) using Python's `random` module with a fixed seed (`SEED = 42`).

It is labelled throughout the project as:

> *"Synthetic dataset generated for educational AI/ML demonstration."*

#### What the dataset IS:

- Statistically plausible synthetic values for nitrogen, phosphorus, potassium, temperature, humidity, soil pH, rainfall, crop type, and estimated yield.
- Programmatically constructed from agronomically reasonable ranges, with intentional noise added.
- Fully reproducible: running `python generate_dataset.py` always produces the identical CSV.

#### What the dataset IS NOT:

- ❌ Not a public dataset (Kaggle, UCI, government portals, etc.)
- ❌ Not downloaded from any external source
- ❌ Not derived from real farm measurements
- ❌ Not linked to any specific geographic region, farm, or organisation
- ❌ Not representative of real agricultural outcomes

#### Personal Information

This dataset contains **no personal information of any kind**. Specifically, it does not include:

- Farmer names
- Phone numbers or email addresses
- Physical addresses or GPS coordinates
- Aadhaar numbers, PAN, or any identity document numbers
- Private agricultural records
- Any other sensitive or personally identifiable information (PII)

#### Reproducibility

The random seed is fixed at `SEED = 42` inside `generate_dataset.py`. Any person running the script on any machine will obtain the identical 3 000-record CSV file.

#### Provenance file

A machine-readable provenance note is written alongside the CSV at `data/README_data.txt` every time the generator runs.

## Deployment

### Backend → Render (FastAPI)

1. Push this repo to **GitHub**
2. Go to [render.com](https://render.com) → **New → Web Service**
3. Connect your GitHub repo — Render auto-reads `render.yaml`
4. It will automatically:
   - Install dependencies
   - Run `generate_dataset.py` (creates CSV)
   - Run `train_model.py` (trains models)
   - Start FastAPI with `uvicorn`
5. Copy your Render URL (e.g. `https://crop-advisory-api.onrender.com`)

### Frontend → Vercel (Static HTML)

1. Go to [vercel.com](https://vercel.com) → **New Project**
2. Import the same GitHub repo — Vercel reads `vercel.json`
3. It will serve the `frontend/` folder as a static site
4. **After deploy:** open `frontend/app.js` and replace:
   ```js
   const BACKEND_URL = "https://your-app-name.onrender.com";
   ```
   with your actual Render URL, then push — Vercel auto-redeploys.

### Local Testing (before deploying)

```powershell
# Terminal 1 — start backend
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload

# Terminal 2 — serve frontend (any static server)
cd frontend
python -m http.server 5500
```

Open `http://localhost:5500` in browser.
Then update `BACKEND_URL` in `frontend/app.js` to `http://127.0.0.1:8000`.
