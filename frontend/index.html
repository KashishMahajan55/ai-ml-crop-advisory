ℹ️ About This Project

🤖 Models

Random Forest Classifier for crop recommendation (64% accuracy across 20 crops) and Gradient Boosting Regressor for yield estimation (R² = 0.80).

📦 Dataset

3,000 synthetic records generated by generate_dataset.py with a fixed random seed (42). No real farm data. No personal information.

🔒 Privacy

No names, phones, emails, addresses, GPS, or identity numbers. Clearly labelled as synthetic throughout the project.

⚙️ Stack

Backend: FastAPI on Render. Frontend: Static HTML/CSS/JS on Vercel. ML: scikit-learn (Python).
